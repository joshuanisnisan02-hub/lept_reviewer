# LEPT Review Hub

A modern LEPT study companion built around the cycle:

**Diagnose -> Learn -> Practice -> Understand Mistakes -> Review -> Retain -> Simulate -> Improve**

## Implemented starter experience

- Responsive Next.js + TypeScript + Tailwind foundation
- Landing page
- Onboarding wizard
- Elementary / Secondary track selection
- Program / specialization selection
- Target exam date and study-time capture
- Demo dashboard with Review Readiness, weak areas, review plan, and recommended next action
- Learning path UI
- Practice generator starter
- Quiz interaction with rationale after submission
- Flashcards starter
- Mistake review starter
- Progress / competency view
- Sources & Alignment page
- Supabase starter schema

## Run

```bash
npm install
npm run dev
```

## Academic content rule

Production coverage must be derived from the latest applicable official PRC LEPT Table of Specifications and current PRC-CHED alignment guidance. CHED and DepEd materials may expand and contextualize competencies, but should not silently replace the examination blueprint.

As of the current source review, PRC Professional Regulatory Board for Professional Teachers Resolution No. 11, s. 2025 amends the Enhanced TOS, and PRC Resolution No. 2053(A), s. 2025 provides implementation guidance for PRC-CHED alignment.

Do not label AI-generated or unreviewed content as verified.
